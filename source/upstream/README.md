# upstream — 上游源码区

EduForge「复用成熟实验环境」的原料库。原则：**上游原样克隆、定点锁定；适配全部写在 EduForge 一侧**（`code/eduforge/services/engine-host/src/adapters/`），不改上游一行。

## 内容

  - **EJSS 的运行时控制面（2026-10-19 实测两个模型，证据 `ejss-runtime-evidence.json`）**：解压后的仿真页里 `window._model` 是全局，`initialize/step/update/play/pause/reset/serialize/unserialize` 都在。烘焙的参数确实是运行时在用的值（Illustration2_6 的 y=45/a=-9.8；Problem2_18 的 y_r=2/v_r=10/a=-9.8，后者 dt=0.02、变量名与Initialization块结构都不同，Initialization 长度实测为 0）；`step()` 不需要动画帧就能推进，轨迹逐点落在解析抛物线上（前者 t=1.9 时 y=27.31099999999999 vs 45−4.9·1.9²=27.311，差 ~1e-13；后者 t=0.1/0.2/0.4 三点全对到 1e-15）。运行时写值也能成：注入 y_r=3.5/v_r=6.0 后一步得 3.61804/5.804，与 `3.5+6·0.02−4.9·0.02²` 逐位相同。**但写入有两个静默失效条件**（都不报错、都不改状态，是我自己踩出来后单独测出来的）：① `unserialize()` 必须收到 `serialize()` 的**完整信封**（`{"model":…,"view":…}`），只把里面的 `model` 子对象传回去就等于没写；② 直接改字段 `_model.y_r=1.25` 读回来是 1.25，`step()` 之后引擎仍按原轨迹走 ⇒ 真正的状态不在顶层字段上。所以 Agent 侧的验收必须「写 → 立即 serialize 回读比对注入值」，不能只看有没有异常。另一条：同一 tick 里调 `initialize()` 后立刻读，`t` 并不会被重置（实测跑完 20 步再 initialize，t 仍是 0.12）⇒ 要干净初值就重载页面。落地时刻 3.099994 vs 解析 3.030458（+2.29%）是步长量化（事件只在 dt=0.1 的格点上判），不是积分误差。**这条面后来被搬到命令行并量到整批**：`../library/ejss_headless_lab.mjs`（playwright-core + 本机 Playwright 缓存里的 chromium，`file://` 打开本目录拼出的包）与 `../library/ejss_headless_sweep.mjs` 对 25 个 EJS 6.02 包逐个跑「基线/重载复现/干净页面先写后跑」三趟，实测 25/25 零异常加载、25/25 全套 8 个方法、25/25 轨迹可复现，写值 23 个落地且改变行为、24 个落地（证据 `../library/ejss-headless-sweep.json`）。两个未过的包是**选靶规则的锅**——探针挑「步内变化最快的量」注入，而 2.12 的 `a`、2.13 的 `x_hill` 是模型每步重算的派生量，写成「包不可控」就是假陈述。

- **上游没装成之前，别急着写「找不到权威来源」**。本轮两条旧结论都被推翻了：OSP 的组织名是 `OpenSourcePhysics`（旧记录猜 wejen/osp-tools/compadre-io 全 404 就判「不装」），3JCN 是静态站（旧记录判「Java applet 时代不可锁定」）。正确动作是先打 `api.github.com/orgs/<候选>/repos`、`api.github.com/search/repositories?q=…` 与站点 HTTP 头，拿到返回再下结论；结论被推翻时在 lock 里写明撤销了哪句（本轮已写）。
- **仓库根没有 LICENSE 文件 = 许可未定，不是「默认可以用」**。`osp/` 与 `osp_ejs/` 实测无 LICENSE/COPYING，只能只读参考；要进任何交付包，先取得书面授权说明并登记进 lock。
- **EJSS 的 `<Domain>` 不是「可改」的开关**。它只在带参数页的模型里出现，导出包普遍省略；如果按 `domain == "public"` 过滤，26 个有参数表的模型会被误判成 0 个。`probe_ejss_model.py` 现在按「省略也算可调，只排除 internal/private」计数，并把 `domain_declared` 单独记下来。
- **「包里带运行时」不能推出「浏览器里能打开」；反过来，「这个包里有打不开的文件」也不能推出「仿真页打不开」**。`survey_ejss_models.py` 对整包所有 HTML 计数得 28/28 引用包外资源、27/28 引用包内不存在的目录名——一度被我写成「这批包都得先拼树」，那是把 `EjsLauncher.html`、`<Name>_Contents.xhtml` 这类包装页和仿真主页面混在一起了。按页面分开量之后：26 个有仿真主页面的包里，主页面引用缺失文件的为 **0**，远程加载为 0 的有 **25**（唯一例外是 webejs 那份，6 处 CDN，已在浏览器里拼树跑通）。教训留在两处：交付前要在浏览器实测（`assemble_ejss_offline.py` 做通过的那份含三处必需修补：本地运行时、plotly 1.x、能跑回调的 MathJax 替身），以及**计数要写清统计口径**，否则同一批数字能同时支持两个相反的结论。
- **两个静默失效的探针/写法，都会把「没有」读成「坏」**。① `probe_ejss_model.decode()` 原来先试 utf-16：不带 BOM 的偶数长度 UTF-8 会被它静默解成乱码，survey 一度报「26 个包都没有 `_model`、0 个包要改 CDN」——靠直连 grep 的对照值才抓住。② 对 EJSS 模型 `unserialize()` 只喂 `serialize()` 里的 `model` 子对象、或直接改 `_model.<字段>`，都不报错也不生效。两者的共同点：失败是静默的，所以判据里必须带「写后回读」与「换一种读法对照」。
