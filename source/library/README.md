# source/library — 实验资源目录（Agent 可直接消费的那一层）

职责：把「装了哪些上游引擎」和「教师能挑哪些实验」连起来。`source/upstream` 回答的是磁盘上有什么，这里回答的是**每个实验用哪个引擎、种子文件在哪、Agent 能改哪些参数、改完拿什么独立公式验收**。

## 内容

- `experiments.json` — 目录本体。11 个引擎条目 + 18 个实验条目 + 1 条「本轮没装」的记录（只剩 PhET 官方发布成品那一条，5 种 URL 形态实测 404/TLS 失败）。实验按 P0/P1/P2 分优先级（实测计数：P0 9 条、P1 7 条、P2 2 条）；状态词有七种（`template_connected` / `engine_headless_verified` / `component_headless_verified` / `engine_browser_verified` / `resource_installed` / `installed_catalog_only` / `reference_only`），含义写死在文件开头的 `status_words` 里，避免把「装了源码」说成「接通了」。当前分布（2026-10-19 实测，**18 条全部达到「引擎真出数、解析式判对错」**）：`engine_headless_verified` 12 条（平面镜、折射、全反射、凹透镜、三棱镜、单摆、弹簧振子、**理想气体状态变化**、**绳波与波速**、**太阳系与开普勒定律**、**牛顿摆**、**双缝干涉**）、`component_headless_verified` 3 条（3D 自由落体、平抛/斜抛、带电粒子在磁场中）、`engine_browser_verified` 3 条（欧姆定律、串并联、RC 充电，浏览器里读引擎自己的电气量）；`resource_installed` 与 `template_connected` 当前 0 条——前者已清零，后者要等 `code/eduforge` 侧的模板三件套。引擎那侧本轮新增两条：`osp-ejss`（6 仓源码落盘，**控制面已由 `interference_lab.mjs` 实测走通一条**：读 `.ejss` 参数表 → 执行模型自己的函数 → 对解析式）与 `3jcn-catalog`（`reference_only`，只有目录）。
- `optics_hall.mjs` + `optics-hall-evidence.json` — 光学实验馆的验收台（`node source/library/optics_hall.mjs --json`）。五个场景（平面镜 / 折射 / 全反射临界角扫描 / 凹透镜焦距反解 / 三棱镜色散）全部用与引擎无关的解析式判对错，2026-10-19 实测 **5/5 pass**。凹透镜那条从两个屏的束宽反解出 |f| = 100.00000000000037（设定 −100），全程不读引擎自报的焦距；三棱镜那条由脚本自写一套矢量斯涅尔追迹（refract + 逐面求交）作对照，两个折射率下屏上落点 −165.5 / −186.5 vs 解析 −165.815 / −186.609，两色差 −21.0 vs −20.793。
- `projectile_lab.mjs` + `projectile-lab-evidence.json` — 抛体验收台（`node source/library/projectile_lab.mjs --json`），引擎是 npm 组件 matter-js。先做**单位标定**（实测律 `a = gravity.y × gravity.scale × 1e6`，自由落体反解 9.80000 m/s²），再拿解析式判平抛（时间 2.0182 s vs 2.0203、射程 30.2733 vs 30.3046）、斜抛 45°（射程 40.7574 vs 40.8163、最高点 10.1746 vs 10.2041）、互补角等射程（30°/60° = 0.9991，**判据里不含 g**，单位标定错了也瞒不过去）。2026-10-19 实测 **5/5 pass**。
- `field3d_lab.mjs` + `field3d-lab-evidence.json` — 3D 电磁验收台（`node source/library/field3d_lab.mjs --json`），引擎是 `@dimforge/rapier3d-compat`。Rapier 不懂洛伦兹力，所以力由脚本每步 `qv×B` 施加，验收用**自写最小二乘圆拟合**（不读引擎自报的任何量）：半径 3.3597 vs `mv/(|q|B)`=3.3333、角速度 1.19999 vs 1.2、由累积转角反出的周期 5.23603 vs 5.23599、拟合残差/半径 0.285%、q 反号则旋向反号、螺旋螺距 7.8566 vs `v∥·T`=7.8540、q=0 时侧向偏移 0。2026-10-19 实测 **5/5 pass**。
- `collisions_lab.mjs` + `collisions-lab-evidence.json` — 碰撞/动量验收台（`node source/library/collisions_lab.mjs --json`），**同一套解析式分别喂给 matter-js 与 Rapier**。结论 6/9 pass，而且败的那三条比赢的更有用：Rapier 的弹性碰撞全中（等质量 4/−2 → −2/4 精确、2 kg 撞 1 kg 得 1.66667/6.66667、弹性斜碰出射夹角 90.000° 且 |vA|²+|vB|² = 25.000、restitution=0.5 时动量守恒而动能掉 37.5%）；Matter 的自由-自由弹性正碰把 10 J 吃到 1.21 J，「n 进 n 出」的牛顿摆两个引擎都不成立（Rapier 5 球排一列被撞后 4 球同动、末端只拿到 1.588 m/s）。⇒ 动量守恒定量交付只能用 Rapier 或专用一维硬球模型，牛顿摆这条**不许**标成已验证。
- `circuit_harness.html` + `serve_circuitjs.py` + `circuit-lab-evidence.json` — 电学验收台（唯一走浏览器的一条，因为 CircuitJS1 的产物是 GWT 编译的 JS）。官方 JavaScript 接口只有 12 个方法且**没有元件参数 setter**，所以「Agent 改参」的路径是 `importCircuit(整份电路文本)`；读数用 `getCurrent()`/`getVoltageDiff()`（double）与 `getInfo()`（渲染串，只有 4 位有效，别当高精度用）。2026-10-19 实测 5/5 pass：欧姆 R=100 ⇒ 50 mA；把 R 改成 470 Ω ⇒ `getCurrent()` = 0.010638297872340425 A，与 5/470 逐位相同（「改参→引擎跟着变」的硬证）；串联 100+220 处处 15.625 mA、分压 1.563+3.438 = 5.001 V；并联两支路 50 / 22.727 mA、Req 68.75 Ω；RC 充电 Vc(0.084 s) = 2.830616 V（解析 2.8418，偏 0.39%，成因是引擎自报时间与状态差约 1~2 步长）。
- `gas_lab.mjs` + `gas-lab-evidence.json` — 热学验收台（`node source/library/gas_lab.mjs --json`），引擎是 `@dimforge/rapier3d-compat`。**关键设计是别把「小球在动」当成「气体有压强」**：压强只从引擎自己给出的速度反转里算（逐分量 `|Δv|` ⇒ 冲量 = m·Δv），球间碰撞用 `collisionGroups` 关掉才是真理想气体；随机源是自写 LCG（不用 `Math.random`，否则证据不可复现）。2026-10-19 实测 **6/6 pass**：基准 p 0.855085 Pa vs 有限半径修正式 0.823045（3.893%）、三轴各向同性 0.992606（0.739%）、弹性撞墙前后 ⟨v²⟩ 漂移 0%、质点极限（R=4 mm）对课本式 p = Nm⟨v²⟩/(3L³) 偏 4.894%、玻意耳 2.08236、等容升温 1.99666、分子数翻倍 2.00013、开重力对照 y 轴受力比 2.0288。
  - 这条线最大的收获是**误差被解释成物理而不是被放宽**：一开始实测 p 比质点公式高 29~31%，扫 `dt`/CCD 得 ⟨v²⟩ 漂移 0.00% ⇒ 不是解算器吃能量；把分子半径算进去（球心只能在 `L−2R` 里往返）后预测倍数 `L/(L−2R)`=1.111，实测 1.154，剩下 4% 才是统计噪声。这正是范德瓦尔斯 b 项的方向，模板里该当成教学点讲，而不是藏起来。
  - **统计量有下限**：`T_RUN=0.6 s`（每分子约 3 次撞墙）时 p 偏 +31%；现在钉的是 N=120、跑 12 s、每分子约 33 次撞墙才有 4% 级误差。写模板时要把 N 与 T_RUN 当下限锁死，否则「误差 ≤5%」是空话。
- `wave_lab.mjs` + `wave-lab-evidence.json` — 绳波验收台（`node source/library/wave_lab.mjs --json`），引擎是上游 myPhysicsLab 的 PDE 模块 `sims/pde/StringSim.js`（leapfrog 格子，左端由「驱动块」的位移强制、右端 `wNew[N]=0` 固定）。只改上游的参数（tension/density/damping/timeStep），判据全用解析式。2026-10-19 实测 **5/5 pass**：波速 3.179644 vs √(T/μ)=3.162278（0.549%）、Δt 减半复现比 0.9988；μ×4 ⇒ 速度比 0.494186、渡越时间比 2.0235；固定端反射峰 +0.063536 → −0.063533（比值 0.9999，到达时刻 6.45 s vs 解析 6.45148）；扫频峰值落在 f₁（0.9999966），f₁/1.3f₁ 振幅比 7.635；CFL 0.8282 合规 vs Δt 翻倍 1.6563 立即炸。
  - **踩到的两个坑**：① 中点探针正好是二次模态的**节点**，只看中点会把 2f₁ 的共振读成 0 —— 共振判据必须取全绳最大位移；② 上游 `getPoint(idx, point)` 要求传入带 `setTo` 的可变点，而这个版本的 `Vector` 是不可变的（全仓 grep 不到 `setTo` 实现），脚本自带最小 shim。
- `kepler_lab.mjs` + `kepler-lab-evidence.json` — 天体验收台（`node source/library/kepler_lab.mjs --json`），引擎是 Rapier：重力关掉，中心平方反比力由脚本每步 `addForce(-GM·m·r̂/r²)` 施加，单位取 `GM = 4π²`（AU、年）使 `T² = a³` 本身就是解析基准。2026-10-19 实测 **6/6 pass**：圆轨道周期 1.0011167 yr vs 1（0.112%）；两条椭圆（e≈0.37 / e≈0.10）的 T²/a³ = 0.99859881 / 0.99955356；比角动量波动 0.0737%（Δt 缩到 1/4 ⇒ 0.0421%）；vis-viva 三点 ≤0.122%；**行星质量 1→50 周期比 0.99999667**（轨道与质量无关）；关掉中心力后 y = v·t 误差 0.09% 且 x 一位不动；Δt 减半 ⇒ 周期误差比 1.976（一阶累积）。
  - 圈数不够时脚本**返回 NaN 让判据显式失败**，不静默给 0：第一版就是因为「2 年只数到 2 个过节点」把周期算成 0，看起来像物理崩了，其实是窗口取短了。
- `cradle_lab.mjs` + `cradle-lab-evidence.json` — 牛顿摆验收台（`node source/library/cradle_lab.mjs --json`），引擎是上游自带的摆模型：`NewtonsCradleApp.make`（静态工厂，不碰 DOM）+ `ContactSim` + `CollisionAdvance`（先求碰撞时刻、再按冲量解的事件式解法）。2026-10-19 实测 **5/5 pass**：末球峰值角/释放角 = 0.999984、交接后首球与中间三球的残余角都是 0、末球出射与首球入射的 |ω| 比 0.999954、二进二出时末两颗都摆到 0.78539 而中间那颗仍是 0；对照组把 elasticity 从 1 改到 0.5 ⇒ 末球只剩 0.3091 倍释放角、中间球被带到 0.15322（证明判据真的跟着参数变，不是常数 1）。前置校验是同一条摆的大角/小角周期比 1.03966 vs 解析 1 + θ0²/16 = 1.03855（0.106%）。
  - 这条是**换引擎换出来的**：collisions_lab 已经证明 Matter（10 J → 1.21 J）与 Rapier（5 球被撞后 4 球同动）都复现不了 n 进 n 出，两条线的负结果原样保留，没有为了 pass 去改判据。
  - 三个 API 坑都是本轮踩出来的：`setElasticity` 必须晚于建模、步进方法是 `advance.advance(dt)`、`getBody` 对缺失的球是抛异常而不是返回 null；能量总量在 `getEnergyInfo().getTotalEnergy()`，没有 `.total` 字段。
- `interference_lab.mjs` + `interference-lab-evidence.json` + `../upstream/probe_ejss_model.py` — 双缝/多缝干涉验收台（`node source/library/interference_lab.mjs --json`），也是 **EJSS 这条线的第一条可复用 Agent 路径**：`probe_ejss_model.py` 解开 `webejs_model_MultislitDiffraction.zip`、按 UTF-16 读 `_source.ejss`、列出 22 个 public 参数（N/D/d/lambda/L…）与模型自带的 JS 代码块；`interference_lab.mjs` 取 `Osejs.Model.Library` 里 `getSingleSlitAmp`/`getMultiSlitAmp` 的**原文**用 `new Function` 执行，改参数就是改传进去的 N/d/D/λ/L，判据全用与模型无关的解析式。2026-10-19 实测 **5/5 pass**：主极大间距 0.3995078 vs `λL/d`=0.4（0.123%）、单缝包络第一极小 4.001465 vs 4（0.037%）且同一处第 10 级主极大 `d/D=10` 恰好缺级（I = 1.34e-7）、次极大个数 N=1/2/3/5 时 0/0/1/3 全等 `N−2`、λ×2 ⇒ 间距比 2.00032 而 d×2 ⇒ 0.5004801、归一化陷阱对照组（各 N 中央强度恒为 1）。
  - **两个必须写进模板的坑**：① 模型绘图窗只有 ±π，装不下 `λL/D = 4` 的包络零点 ⇒ 取样范围要脚本放宽（函数是纯的，放宽范围不改模型）；② 上游把多缝振幅**除以 N** 归一化，中央主极大永远 = 1，所以这张图**不能**用来讲「缝越多主极大越亮（∝N²）」，要讲得自己按未归一化的 `(sin Nβ/sin β)²` 出数。视图层（EJSS 的 plot/Shape 描述）本轮没执行，只验了物理函数与参数表。
- `check_catalog.py` — 校验器。除了把 `install_path`/`seed`/`npm_component`/`measured_evidence`/证据路径逐条拿去 `os.path.exists`（**missing 必须为 0），还做三项自检：状态词必须在 `status_words` 里有定义、实验引用的 engine id 必须存在于 `engines`、标 `*verified` 的实验必须带 `measured_evidence`（防「口头已验证」）。2026-10-19 本轮实测：`paths checked: 68 | missing: 0`，三项自检各 0 项问题（「measured_evidence 混进中文括注导致路径不可查」这一条就是它先逮出来的，已拆成 `measured_evidence` + `measured_note`）。

跑校验（仓库根目录）：

```bash
python source/library/check_catalog.py   # 退出码 0 = 路径全通
```

## 与上下层的关系

## 已知的坑与纪律

1. **状态词不许拔高**。18 条实验**全部**达到了「本机真跑出可对账的物理量」（`engine_headless_verified` 12 + `component_headless_verified` 3 + `engine_browser_verified` 3）：5 条光学（`optics_hall.mjs`：平面镜 200.5 vs 解析 200、折射 449.5 vs 450、临界角落在 (40°,42°] 对上 asin(1/1.5)=41.81°、凹透镜由束宽反解出 |f|=100.00000000000037、三棱镜两 n 落点 −165.5/−186.5 vs 自写矢量斯涅尔 −165.815/−186.609）、单摆（2.00835 s vs 2.00834 s）、弹簧振子（a=−1.1999976 vs −kx/m=−1.2，周期 3.14159 vs 2π√(m/k)）、**理想气体（p 0.855085 Pa vs 有限半径修正式 0.823045、三条状态律比 2.08236/1.99666/2.00013）**、**绳波（v 3.179644 vs √(T/μ)=3.162278、反射峰反号、扫频峰值落 f₁）**、**开普勒（两条椭圆 T²/a³ = 0.99860/0.99955、质量 1→50 周期比 0.99999667）**、抛体（射程 30.2733 vs 30.3046、互补角比 0.9991）、**牛顿摆（末球峰值角/释放角 0.999984、二进二出、elasticity 对照组）**、**双缝干涉（间距 0.3995078 vs λL/d=0.4、包络零点 4.001465 vs 4、缺级 I=1.34e-7、次极大数 = N−2）**、3D 自由落体（15.075 vs 15.095）、3D 带电粒子（半径 3.3597 vs 3.3333、周期 5.23603 vs 5.23599）、电学 3 条（CircuitJS1 在浏览器里读自己的电气量：R=470 Ω ⇒ 0.010638297872340425 A 与 5/470 逐位相同；串联 15.625 mA 与分压 1.563+3.438 V；并联 50 / 22.727 mA、Req 68.75 Ω）。但「18/18 已验证」**只到物理层**：这 18 条都还没有模板三件套与适配器接线（当前只有凸透镜那条线有），也没有一条把视图/交互层跑通——`interference_lab.mjs` 执行的是模型自己的物理函数，EJSS 的绘图描述本轮没执行。引擎能算出对得上的数 ≠ 教师能一句话定制并拿到离线包。
2. **光学的两个静默陷阱**（本轮实测踩过）：点必须写成 `{x,y}`，写成 `[x,y]` 时 `loadJSON` 不报错但光线一步就没了；`PlaneGlass` 的玻璃在 `p1→p2` 的**左手侧**，光源放错侧时「全反射」会退化成光在空气里直走而**看起来仍然通过**。所以验收台自带一条 `refIndex=1.0` 的对照跑：先证明几何基线，再谈物理。
3. **PhET 的 main 分支是空壳**。各仿真仓库 main 只剩 README.md + doc/（实测 3~5 个文件），完整源码在 X.Y 发行分支上；`experiments.json` 里记录的 sim 路径全部指向 `source/upstream/phet/sims/<name>`（发行分支克隆）。`circuit-construction-kit-common` 只有 main，是这批里唯一的空壳。
4. **许可义务要在装的时候就写清楚**，不要等到分发前。GPL-2.0（circuitjs1）、GPL-3.0（PhET 仿真源码、OSP 家族的 webejs/resources/csm/STP）、AGPL-3.0（Stellarium Web Engine）各有不同的触发条件，已分别登记在 `experiments.json` 的 `license_obligation` 里。本轮新增一条硬事实：`../upstream/osp/` 与 `../upstream/osp_ejs/` **仓库根没有 LICENSE 文件**（`inventory.json` 的 `license_files` 实测为空）⇒ 许可未定，只读参考、禁止进任何交付包。
5. **「查不到来源」必须是查过的结果**。上一轮把 OSP@Singapore/EJSS 与 3JCN 写进 `not_installed`，理由是「找不到权威仓库」，但当时只猜了三个组织名。本轮实测 `api.github.com/orgs/OpenSourcePhysics/repos` 返回 13 个仓库、`www.new3jcn.com` 是可抓的静态站 ⇒ 两条旧结论已在 lock 里显式撤销，`not_installed` 里现在只剩 PhET 官方发布成品一条（5 种 URL 形态实测 404/TLS 失败）。同时记住反面：**装上了也不等于能控**——`3jcn-catalog` 至今只有目录（控制面 pending），`osp-ejss` 的控制面本轮才算**测通了一条**（读 `.ejss` 参数表 + 执行模型自己的函数），其余 EJSS/OSP 模型能不能同一条路走还没逐个验。
6. **改完这个 JSON 必须重跑校验**。路径写错在肉眼 review 时最难发现，而 Agent 取种子时必然踩。
