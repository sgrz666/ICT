# 08_requirement_classes/ — 教学需求类型学分类与规则集

**职责**：将自然语言教学需求拆解归类为认知层次、互动类型、控制维度等标准化需求类型，支持需求理解 Agent 稳定映射。

## 内容

| 文件 | 说明 |
|---|---|
| `build_classes.py` | 需求分类清单与规则导出构建脚本 |
| `需求类型清单.json` | 需求分类定义与识别特征 JSON 库 |
| `需求类型清单.csv` | 便于对齐与核查的 CSV 视图 |
| `需求类型与全量映射.md` | 需求类别与实验模板的映射规则说明 |

## 与上下层的关系

- **父层索引**：[`../README.md`](../README.md)。
- **业务关联**：与 `../01_single_agent/` 的需求理解模型 prompt 形成规则对齐。
