# 跨学科案例清单

跨学科案例候选清单。字段可直接映射为 01 需求理解 Agent 的输出，用于批量跑流水线。

## 形态定义

| 形态 | 含义 |
|---|---|
| A | 参数 → 数值 → 曲线 |
| B | 参数 → 几何构型 |
| C | 参数 → 枚举/计数 |
