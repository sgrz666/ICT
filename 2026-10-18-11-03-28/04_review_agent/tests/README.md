# 04_review_agent/tests — 审查器自测与回归用例目录

本目录存放审查角色（`04_review_agent`）评判规则与浏览器探测脚本的自测夹具与回归测试用例。

## 目录职责与内容

- **职责**：验证审查器本身的判决准确性与灵敏度，防止审查器出现假阳性（将坏页面判高分）或假阴性（误杀好页面）。
- **主要文件**：
  - `test_judges.py`：测试各评判函数（公式提取、数值对账、DOM结构检查）的单元测试。
  - `broken_example.html`：人工构造的缺陷样本页面（含死按钮、JS错误、公式计算错误），实测评分需被压低至 27.5 分以下并精准点名所有缺陷。
  - `formula_samples.html`：包含各种合法物理公式书写形式的正例样本。
  - `text_overlap_example.html`：文字排版与重叠负例样本，用于测试无头浏览器的视觉与布局判决。

## 与上下层的关系

- **上游**：人工构造的自检对抗样本与 pytest 测试套件。
- **下游**：保障 `04_review_agent` 在流水线运行中的判决可靠性。

## 已知的坑与纪律

- 每次新增审查判据时，必须在此补充对抗负例与通过正例，确保审查器本身逻辑不退化。
