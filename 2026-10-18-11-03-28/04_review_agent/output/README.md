# 04_review_agent/output — 审查质检报告输出目录

本目录存放质检审查角色（`04_review_agent`）对生成的交互实验页面进行自动化规则检查与无头浏览器真实操作评估后的审查报告 JSON 文件。

## 目录职责与内容

- **职责**：保存每次实验审查的结构化打分与详细问题清单。
- **文件命名**：`审查报告_<实验标识>.json`。
- **内容结构**：
  - `total_score`：综合得分（100分制）。
  - `dimension_scores`：维度细分得分（页面可用性、操作交互性、科学计算准确性、教学规范性、UI 布局质量等）。
  - `issues`：检出的具体缺陷项（如按钮无响应、公式与数值不符、文字重叠等），供生成角色做针对性返工。

## 与上下层的关系

- **上游**：`04_review_agent/judges.py` 及 `checks_browser.js` 驱动无头浏览器真实点击与采样判决后输出。
- **下游**：`run_pipeline.py` 判断是否达到及格阈值（如 >= 85分）；若未达标则将意见反哺 `03_generator_agent` 触发返工循环。

## 已知的坑与纪律

- 审查器必须像真实师生一样进行时序交互（如电路需先闭合开关再读取电表，否则会将开路下的 0A 误判为计算错误）。
- 主题公式校验必须绑定当前实验的具体公式，严禁使用固定公式导致跨学科误判。
