# 07_spatial_cases/ — 空间与三维几何实验清单

**职责**：针对立体几何、空间截面、外接球及三维空间旋转等高空间感知维度的数学实验案例进行专题规整与原型验证。

## 内容

| 文件 | 说明 |
|---|---|
| `build_spatial_catalog.py` | 空间案例目录构建与同步脚本 |
| `prototype_section.py` | 正方体空间截面与几何切割算法原型验证脚本 |
| `spatial_cases.json` | 空间三维实验案例定义集 |
| `空间案例清单.md` | 人类可读的空间三维实验需求与交互形式说明 |

## 与上下层的关系

- **父层索引**：[`../README.md`](../README.md)。
- **交付支持**：为后续基于 Three.js 的空间截面和外接球交付实验提供数学模型基础。
