# 01_single_agent/output — 需求结构化输出目录

本目录存放需求理解角色（`01_single_agent/agent.py`）调用大模型解析教师原始需求后生成的结构化 JSON 文件。

## 目录职责与内容

- **职责**：持久化需求理解智能体的单次运行产物，供后续知识检索（`02_retrieval_agent`）及实验生成（`03_generator_agent`）按需求名匹配使用。
- **文件命名**：`需求_<主题>_<时间戳/标识>.json`（例如 `需求_欧姆定律_*.json`、`需求_浮力_*.json`）。
- **字段契约**：包含 8 项核心字段（实验名称、学科、教学目标、核心变量、交互控件、测量读数、公式与结论判断依据、安全与边界提示）。

## 与上下层的关系

- **上游**：`01_single_agent/agent.py`，根据用户输入字符串调用模型完成解析并写入本目录。
- **下游**：`02_retrieval_agent` 读取对应的主题和变量需求以实施 BM25 多路召回；`run_pipeline.py` 在全流程编排中将对应文件归档至 `runs/<时间戳>/01_需求.json`。

## 已知的坑与纪律

- 需求文件必须与知识包严格按需求标识配对，禁止盲目「取最新文件」，否则多任务并发或历史多轮次时会产生需求与知识错配。
- 本目录为运行中间产物暂存区，生产归档以 `runs/` 下的时间戳档案为准。
