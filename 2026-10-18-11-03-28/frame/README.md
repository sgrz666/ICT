# frame/ — 统一设计系统与学科 UI 框架

**职责**：提供跨学科通用的实验外框、响应式布局、统一调色板、通用控制面板组件以及各学科专有画布辅助 JS 库。

## 内容

| 文件 | 说明 |
|---|---|
| `frame.css` / `normal.css` / `exp.css` | 统一全局样式、重置样式与实验内部组件样式 |
| `phys.js` / `chem.js` / `math.js` / `bio.js` / `geo.js` / `cs.js` | 各学科专有仿真画布与数据图表辅助组件 |
| `vis.js` / `typo.js` | 可视化交互与排版辅助库 |
| `shell.html` | 实验包裹外框骨架模板 |
| `UI规范.md` | 六学科统一质感与排版设计规范 |
| `场景库说明.md` | 场景库组件使用说明与接入示例 |
