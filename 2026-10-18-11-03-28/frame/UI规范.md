# 页面 UI 规范（平台统一层）

> 适用范围：**所有生成出来的教学案例页**。
> 实现位置：`frame/normal.css` + `frame/typo.js` + `frame/shell.html` + `shell.py`。
> 验收位置：审查器第 4 关 `G4-09 版式统一`，以及 `tools/ui_audit.js`。
>
> **现行字号 = 最初版本的 2 倍**（2026-10-24 调整）。原始档位 13 / 13.5 / 14 / 14.5 / 19px
> 对应现在是 26 / 27 / 28 / 29 / 38px。

## 为什么放在外壳，不放提示词

这三条是「30 个页面必须长得一样」的约束，不是「这个实验该怎么画」。
交给模型每次重写一次，一定会漂移（今天蓝色条里塞一整句主题，明天 ① 区又重复一遍名字）。
所以统一在外壳层做，模型改不动：

```
frame.css → exp.css → 页面自带样式 → normal.css（最后加载，强制覆盖）
                                     ↑ 正文纯黑 / 最小字号 / 名称只留页眉
```

`typo.js` 在外壳脚本之后运行，负责兜住页面自己写死的小字号和自选颜色。

## 四条规范

### 1. 正文文字一律纯黑 `#000`

- 覆盖范围：学习目标、教学说明、表格、注释、代入式、提示语、字段标签
- 保持原色（语义色，不算正文）：学科/年级胶囊标签、按钮、读数数值 `.v`、
  代入式里的结论 `<em>`（橙色）、页脚（浅灰）
- 两层实现：
  - CSS：`normal.css` 对正文容器直接 `color:#000 !important`
  - JS：`typo.js` 的 `fixColor()` 逐个文字节点判断**底色明暗**——
    浅底彩字改黑，深底白字保持不动（避免把深色按钮上的白字涂黑）

### 2. 最小字号 26px（原始 13px × 2）

| 档位 | 现字号 | 原字号 | 用在哪 |
|---|---|---|---|
| 最小 | **26px** | 13px | 胶囊标签、区标题旁提示、读数名、按钮、表格备注、页脚、tooltip、页眉侧栏 |
| 说明 | **27px** | 13.5px | 代入式、提示 note、警示块、实验记录表 |
| 正文 | **28px** | 14px | 学习目标、教学说明正文、⑥ 区 h3 |
| 标题 | **29px** | 14.5px | 六区域标题 `② 演示`、教学说明折叠头 |
| 读数 | **38px** | 19px | ④ 区读数数值 `.v` |
| 页眉 | **36px** | 18px | 蓝色条实验名字 `.pf-page` |

- `normal.css` 里改 `--pf-fs-min` 一处即可全站生效
- `typo.js` 在加载后 + DOM 变动后扫一遍，把任何低于门槛的字抬到门槛
- 画布里的字是位图，CSS 管不到：由 `vis.js` / `chem.js` 的 `fs()` 统一乘 `TYPE_SCALE = 2`，
  下限分别是 25px / 24px（原来是 12.5 / 12）

### 3. 实验名称只在页眉出现一次

- 蓝色条：`师伴-` + **实验名字**（≤16 字），不再塞整句「实验主题」
- ① 区：不再写 `.exp-name` 大标题（外壳装配时整节点摘掉，`normal.css` 里再兜一层 `display:none`）
- 名字从哪来：需求 Agent 的 `实验名称` 字段；没有就由 `shell.short_title()` 压缩：

| 原始主题 | 压成 |
|---|---|
| 用平面截正方体所得截面形状随平面位置与倾斜角度变化的规律 | 平面截正方体 |
| 铁与硫酸铜溶液发生置换反应，生成铜和硫酸亚铁，验证金属活动性顺序 | 铁与硫酸铜溶液反应 |
| 凸透镜成像规律：物距变化对像的大小与位置的影响 | 凸透镜成像规律 |
| 浮力：阿基米德原理与浮沉条件 | 浮力：阿基米德原理与浮沉条件（冒号前太短，不拆） |

压缩规则：冒号取主标题（≥3 字才拆）→ 取第一分句 → `发生置换反应→反应` →
砍「所得/随/并/的规律」后的尾巴 → 去开头「用/通过/利用/借助」→ 超 16 字截断。

### 4. ④ 结果与反馈紧贴 ② 演示下方

主区网格改成：

```
┌──────────── ② 演示 ────────────┬── ③ 参数与操作 ──┐
├──────────── ④ 结果与反馈 ──────┘                  │
└───────────────────────────────────────────────────┘
```

- `grid-template-areas: "stage control" / "result result"`
- ④ 横跨整行：读数在 ≥1180px 视口一行铺四个，窄屏退回两列
- ③ 默认被拉到与 ② 等高，内部 `justify-content: space-between` 均分，
  最小行距 26px；**参数特别少**（内容比画布矮 280px 以上）时 `typo.js`
  的 `fitControl()` 给它加 `.is-short`，退回内容高度，不做成一个空壳

原来的布局是「左画布 / 右③+④」，③④ 比画布高得多，画布下方会挖出一大块
空白。把 ④ 挪到 ② 下面正好填上，页面也更符合「先看演示、再看结果」的阅读顺序。

## 字号翻倍时，版式必须跟着改的地方

字大一倍，原来的格子宽度就装不下了。这些不是审美，是「不挤、不裁、不变形」的下限：

| 位置 | 改法 | 不改会怎样 |
|---|---|---|
| `.exp-grid` 右栏 | `minmax(460px, 1fr)`，`align-items: stretch` | 右栏太窄，读数名一行放不下；参数区与画布不齐高 |
| `.exp-canvas-box` | `aspect-ratio: 16/11` + `max-height: 640px` | 画布被拉长，图形缩成一条 |
| `.exp-read` | `box-sizing: border-box` + 默认两列、≥1180px 四列 | 50% 只算内容区，加上内边距后一行放不下两个，读数竖成一列 |
| `.exp-table-wrap` | `overflow-x: auto` | 列多的记录表直接顶破卡片 |
| `.exp-btn` | `min-width: 150px`、`padding: 13px 20px` | 26px 的字挤出按钮边框 |
| `--pf-header-h` | 58 → 92px | 36px 的页眉标题顶出蓝色条 |

## 怎么看合不合格

```bash
# 单页体检（打印四条规范的实际测量值；门槛自动读页面的 --pf-fs-min）
node tools/ui_audit.js "页面.html" --shot shots/ui.png

# 字号普查（列出每一档各多少处，查有没有被页面自带样式顶掉）
node tools/font_census.js "页面.html"

# 走完整审查（第 4 关会出「版式统一」一项）
cd 04_review_agent && python reviewer.py --html ../页面.html
```

## 老页面怎么升级

已经生成好的案例页不重跑生成，直接用补丁工具原地升级（可重复执行）：

```bash
python tools/reshell.py deliver/*/*.html          # 批量
python tools/reshell.py 某页.html --dry-run       # 只看会改什么
```

它做四件事：改页眉标题、删 ① 区重复名称、**整段刷新** `normal.css` / `typo.js`、
同步同目录的 `frame.css` / `exp.css` 副本，不碰画面和交互脚本。

> 「刷新」不是「只插一次」：早期版本用 `--pf-fs-min` 是否存在来判断，结果字号从 13px
> 改到 26px 时老页面纹丝不动。现在按 `<!-- 平台阅读规范` 标记定位，整段替换。

## 踩坑记录

- **别把 `1em` 当「不小于」用**：`font-size: max(26px, 1em)` 里的 `1em` 是父级字号，
  胶囊标签会瞬间变成父级大小。最小字号必须写死 px。
- **深底白字不能被「统一变黑」**：按钮、深色胶囊上的字必须跳过，
  否则变成黑底黑字。`typo.js` 是按「祖先底色亮度」判断的，不是按类名。
- **`exec(` 是审查器的一票否决词**：`typo.js` 里取颜色值原本用 `RegExp.exec`，
  被判成「动态代码执行」，页面直接禁止发布。改用 `String.match`。
- **画布文字不受 CSS 约束**：`fillText` 的坐标是「未缩放坐标系」，
  改字号会连带影响标注避让，改完必须逐场景截图复核（`node tools/shot_full2.js`）。
- **`flex-basis: 50%` 配 `content-box` 会失效**：`50%` 只算内容区，加上 padding
  就超过一行，两列变一列。加 `box-sizing: border-box` 才按预期排。
- **页眉 span 可能带 `data-*` 属性**（编辑器回写过），
  匹配要写成 `<span[^>]*class="pf-page"[^>]*>`，否则老页面改不动。
- **门槛别写死在审查器里**：`checks_browser.js` 原本把 `13` 当常量传进 `page.evaluate`，
  改成读 `--pf-fs-min` 之后，规范再调字号审查器自动跟着走。
