## 核心概念
- 图像是抛物线；a > 0 开口向上、有最小值，a < 0 开口向下、有最大值。
- 对称轴 x = -b/(2a)，顶点坐标 (-b/(2a), (4ac-b²)/(4a))。
- |a| 决定开口宽窄：|a| 越大开口越窄，与开口方向无关。
- c 是与 y 轴交点的纵坐标，不是顶点纵坐标。

## 公式与结论
- 判别式 Δ = b² - 4ac：Δ > 0 与 x 轴有两个交点，Δ = 0 有一个，Δ < 0 没有实数交点。
- 两根之和 x₁ + x₂ = -b/a，两根之积 x₁x₂ = c/a（韦达定理）。
- 顶点式 y = a(x-h)² + k 中，对称轴 x = h，顶点 (h, k)。
- 平移规律：y = ax² 向右平移 h、向上平移 k 得 y = a(x-h)² + k。
