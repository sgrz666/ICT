## 器材与步骤
- 步骤一 取镜安放：一手握镜臂、一手托镜座，放在距桌边约 7 cm 处。
- 步骤二 对光：转动转换器使低倍物镜对准通光孔，选较大光圈，左眼注视目镜，转动反光镜直到看到明亮视野。
- 步骤三 放置玻片：把装片放在载物台上，用压片夹压住，标本正对通光孔中心。
- 步骤四 调焦：先从侧面看，转动粗准焦螺旋使镜筒缓缓下降接近玻片；再左眼观察，反向转动使镜筒上升直到看清物像。
- 步骤五 换高倍镜：把要观察的结构移到视野中央 → 转动转换器换高倍物镜 → 调大光圈 → 只转细准焦螺旋调清晰。
- 临时装片（洋葱鳞片叶内表皮）：擦净载玻片 → 滴一滴清水 → 撕取内表皮并展平 → 盖盖玻片 → 一侧滴碘液、另一侧吸引染色。
- 临时装片（人口腔上皮）：擦净载玻片 → 滴一滴生理盐水 → 刮取口腔上皮并涂抹 → 盖盖玻片 → 染色。动物细胞用生理盐水，不能用清水。

## 操作要点
- 镜筒下降时眼睛必须从侧面看物镜，防止压碎玻片。
- 换高倍镜前必须先「把目标移到视野中央」，否则目标会跑出视野。
- 高倍镜下视野变暗，要调大光圈或使用凹面镜。
- 观察时两眼睁开，左眼观察、右眼绘图，这是规范操作。
- 盖盖玻片时先让一侧接触水滴，再缓缓放下，避免产生气泡；视野中的大圆空白边缘发黑即为气泡，不是细胞。
- 染色时把碘液滴在盖玻片一侧，在另一侧用吸水纸吸引，让染液浸润标本。
