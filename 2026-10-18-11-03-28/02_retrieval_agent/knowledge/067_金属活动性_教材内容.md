## 核心概念
- 活动性顺序：K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au，从左到右减弱。
- 排在氢前的金属能与稀盐酸、稀硫酸反应放出氢气；排在氢后的不能。
- 排在前面的金属能把后面的金属从其盐溶液中置换出来（盐必须可溶）。
- 铁与酸或盐溶液发生置换时生成 +2 价亚铁，不是 +3 价铁。

## 公式与结论
- Fe + 2HCl → FeCl₂ + H₂↑；Zn + 2HCl → ZnCl₂ + H₂↑；Mg + 2HCl → MgCl₂ + H₂↑。
- Cu + HCl → 不反应；Ag + HCl → 不反应（氢后金属）。
- Fe + CuSO₄ → FeSO₄ + Cu；Cu + 2AgNO₃ → Cu(NO₃)₂ + 2Ag。
- Cu + FeSO₄ → 不反应（铜在铁后，不能置换铁）。
- K、Ca、Na 过于活泼，投入盐溶液会先与水反应，不能直接置换盐中的金属。
