# 02_retrieval_agent/knowledge — 教学知识库条目目录

本目录存放教学实验生成流水线用于检索的教学先验知识库 Markdown 文件，涵盖物理、化学、生物、数学、地理、信息技术等学科。

## 目录职责与内容

- **职责**：为检索角色（`retrieval_agent.py`）提供结构化的学科实验知识底料。每个实验按标准 5 维结构切片组织，支持按主题隔离与 BM25 关键词匹配。
- **结构规范**：每个实验包含 5 项核心切片：
  1. `课标依据`（教学目标、学科核心素养、年级要求）
  2. `教材内容`（典型实验步骤、原理公式、推导过程）
  3. `实验规范`（器材规格、默认初值、读数规范）
  4. `安全约束`（误操作后果、极值红线、边界告警）
  5. `交互设计`（推荐控件类型、视图反馈方式、表格设计）
- **文件规模**：实测收录 155 份标准 Markdown 知识切片文件。

## 与上下层的关系

- **上游**：`seed/` 目录中的建库脚本（如 `build_kb.py`）将初始结构化先验编译为本目录的标准文档。
- **下游**：`retrieval_agent.py` 读取本目录文档，通过 BM25 + 类别保底策略组装 `知识包_*.json`。

## 已知的坑与纪律

- 知识切片严禁跨主题混淆，每个文档首部需明确标注所属实验主题，避免多路召回时电路知识污染力学或化学实验。
