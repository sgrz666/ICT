## 可调参数
a（-2~2，跳过 0）、b（-6~6）、c（-6~6）、显示对比曲线开关

## 可复算量
- 在若干 x 采样点上，用 f(x) = ax² + bx + c 独立重算 y，与页面曲线读数比对。
- 顶点坐标由 -b/(2a) 与 (4ac-b²)/(4a) 重算。
- Δ = b² - 4ac 与页面标注的交点个数是否一致。

## 常见错误
- 认为 c 就是顶点纵坐标（实际是 y 轴截距）。
- 认为 |a| 越大开口越宽。
- 配方时把 y = x² + 4x + 1 写成 (x+2)² + 1（常数项算错，应为 -3）。
