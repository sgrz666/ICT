# 02_retrieval_agent/output — 检索知识包输出目录

本目录存放知识检索角色（`retrieval_agent.py`）针对需求结构化 JSON 检索生成的综合知识包文件。

## 目录职责与内容

- **职责**：持久化针对特定需求的检索命中知识切片集合，包含命中段落原文、BM25 分数、类别保底标签与元数据。
- **文件命名**：`知识包_<实验名称/需求标识>.json`（例如 `知识包_欧姆定律_*.json`、`知识包_浮力_*.json`）。

## 与上下层的关系

- **上游**：`retrieval_agent.py` 从 `01_single_agent/output/` 读取需求，并在 `knowledge/` 库中多路召回后落盘至本目录。
- **下游**：`03_generator_agent` 读取对应知识包注入代码生成提示词；`run_pipeline.py` 将其归档至 `runs/<时间戳>/02_知识包.json`。

## 已知的坑与纪律

- 纯 RRF 检索会整类挤掉「实验规范」与「安全约束」，必须使用 `0.5×RRF + 0.5×相对得分` 并叠加 5 类保底，确保知识包内必定包含安全红线与交互建议。
