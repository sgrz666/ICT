# 学科需求分类（10 学科 · 49 类需求 · J1–J8 判据映射）

按学科组织的需求类型分类。判据 J1~J8 是跨学科复用的审查单元。

## 跨学科审查判据（J1–J8）

| 编号 | 名称 | 独立验证方式 |
|---|---|---|
| J1 | 数值复算 | 页面上的曲线/读数取点回代公式，比对计算结果 |
| J2 | 几何复算 | 验坐标、角度、长度比例与作图约束（如光路可逆、垂直平分） |
| J3 | 计数与守恒 | 枚举结果逐项计数，比对质量守恒/原子数/比较次数 |
| J4 | 空间拓扑 | V−E+F=2、截面共面、边数=相交面数、分割后体积和等于原体积 |
| J5 | 序列与状态 | 逐步比对状态序列；排序类只验合法偏序，不要求唯一序列 |
| J6 | 结构要素齐备 | 要素/环节/标注是否齐备，标注点是否落在目标区域内 |
| J7 | 统计复算 | 最小二乘、均值方差、有效数字修约，独立复算后比对 |
| J8 | 答案表比对 | 唯一解与答案表一致；干扰项必须各有非空错误原因 |
| J0 | 无可复算判据 | 只能验“有没有”，验不了“对不对”——不进闭环 |
