# 10_subject_taxonomy/ — 学科分类法与能力矩阵

**职责**：建立物理、化学、生物、数学等多学科的统一知识分类体系与能力矩阵图，为跨学科实验拓展提供标准分类标签。

## 内容

| 文件 | 说明 |
|---|---|
| `build_taxonomy.py` | 学科分类结构化导出与矩阵数据同步脚本 |
| `gen_matrix_svg.py` | 学科能力矩阵 SVG 可视化生成工具 |
| `学科分类.json` | 树状学科分类与实验知识点索引 JSON |
| `学科分类.csv` | 便于浏览与审核的学科体系表格 |
| `学科分类.md` | 学科知识图谱与分类规范说明文档 |
| `_matrix.svg` | 生成的学科能力矩阵架构矢量图 |

## 与上下层的关系

- **父层索引**：[`../README.md`](../README.md)。
- **运行命令**：`python gen_matrix_svg.py` 重新生成 `_matrix.svg`。

## 已知的坑与纪律

1. **跨学科重叠**：物化交叉（如电化学）按主教学目标归类。
