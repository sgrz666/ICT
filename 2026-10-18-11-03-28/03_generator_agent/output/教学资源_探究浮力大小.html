物理初中八年级课标必做实验

  • 能通过更换不同密度的液体，比较同一物体所受浮力的大小，归纳出浮力与液体密度的关系
  • 能根据实验数据计算排开液体的重力，验证浮力大小与排开液体重力相等（F浮 = G排）

⑥ 教学说明（原理 / 易错点 / 探究问题）

原理

  • 称重法测浮力：F浮 = G − F示，G 为铝块在空气中的重力（2.70 N），F示 为浸入静止后测力计的示数。
  • 阿基米德原理：F浮 = G排 = ρ液 g V排。ρ液 用 kg/m³，V排 用 m³，g 取 9.8 N/kg。
  • 浮力只由 ρ液 与 V排 决定，与物体密度、物体重力、浸没深度无关。完全浸没后 V排 = V物，浮力达到最大值不再变化。

易错点

  • 把 V排 当成物体体积：部分浸入时 V排 < V物，只有完全浸没才相等。
  • 单位换算：1 cm³ = 1×10⁻⁶ m³，1 g/cm³ = 1×10³ kg/m³，漏换算会差 10³ 或 10⁶ 倍。
  • 认为浸得越深浮力越大：深度不进入公式，浸没后继续下沉浮力不变。
  • 把物体密度 2.7 g/cm³ 代入公式：公式里必须是液体密度 ρ液。

探究问题

  1. 保持 ρ液 = 1.0 g/cm³，把 V排 从 0 增到 100 cm³，F浮 如何变化？超过 100 cm³ 后为什么不再增大？
  2. 保持 V排 = 100 cm³，比较酒精、水、盐水三种液体中的 F浮，直线斜率说明了什么？
  3. 记录表中 F浮 与 G排 的差值始终为多少？这验证了什么关系？

结论

浸在液体中的物体受到竖直向上的浮力，浮力大小等于它排开的液体所受的重力：F浮 = G排 = ρ液 g V排。V排 相同时液体密度越大浮力越大；ρ液 相同时排开体积越大浮力越大；物体完全浸没后 V排 不再增加，浮力保持不变，与浸没深度无关。

注意事项

  • 本页为虚拟仿真，参数限定在真实器材范围内：测力计量程 0~5 N、V排 0~200 cm³、ρ液 0.8~1.8 g/cm³；若示数超过 5 N 页面会给出超量程提示。
  • 真实实验中玻璃溢水杯与小桶须轻拿轻放，溢出的水及时擦干防滑；读数时物体须静止且不接触容器底和壁。
