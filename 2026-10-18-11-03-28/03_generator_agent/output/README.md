# 03_generator_agent/output — 生成实验页面输出目录

本目录存放生成角色（`generator_agent.py`）调用大模型生成的交互式教学实验单文件 HTML 产物及元数据。

## 目录职责与内容

- **职责**：保存清洗、校验、内联修复后的单文件交互实验 HTML、元数据 JSON 以及配套 ZIP 交付包。
- **文件命名与形态**：
  - `教学资源_<实验名称>.html`：内联 CSS 与 JS 的单文件可离线交互实验页面。
  - `教学资源_<实验名称>.meta.json`：生成元数据（包含模型、耗时、代码行数与自检状态）。
  - `教学资源_<实验名称>.zip`：打包的独立分发压缩包。
  - `exp.css` / `frame.css`：多学科通用实验框架样式表。

## 与上下层的关系

- **上游**：`generator_agent.py` 结合需求与知识包提示词驱动模型生成 HTML，并调用 `verify_page.js` 完成语法与结构初步校验。
- **下游**：`04_review_agent` 读取此处的 HTML 启动无头浏览器真操作质检；`run_pipeline.py` 归档每轮草稿至 `runs/`。

## 已知的坑与纪律

- 生成 HTML 设有 12,000 字符篇幅预算与自动续写机制，以防触碰 DeepSeek 8,192 token 的单次输出截断限制。
- 严禁依赖外网 CDN 资源，所有样式与逻辑必须自洽内联或引用本地同级公共样式。
