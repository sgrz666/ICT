⑥ 教学说明（原理 / 易错点 / 探究问题）

原理

  • 长方体 ABCD-A₁B₁C₁D₁ 的体对角线 AC₁ 长度为 d = √(a²+b²+c²)。
  • 取体对角线中点 O，则 O 到八个顶点的距离都等于 d/2：这是长方体中心对称性的直接结果（关于 O 中心对称的两点等距）。
  • 因此八个顶点共球，球心 O 为体对角线中点，外接球半径 R = √(a²+b²+c²)/2。
  • 正方体 a=b=c 时 R = (√3/2)a ≈ 0.866a，是长方体的特例。

易错点

  • 把「直径」当成「半径」：R = d/2，不要漏除以 2。
  • 误以为球心在某个面的中心或某条棱上；球心是体对角线中点，不在面上。
  • 误以为只有正方体才有外接球：任意长方体都有，且半径公式统一。
  • 用「外接球」与「内切球」混淆：内切球半径是 min(a,b,c)/2，与本题不同。

探究问题

  1. 把 a、b、c 都调成相同值，观察 R 与棱长的比值是否恒为 √3/2 ≈ 0.866。
  2. 固定 a、b，只增大 c，体对角线 d 与 R 如何变化？画一画 d 随 c 变化的曲线形状。
  3. 若把长方体压扁成 a×b×0 的矩形，外接球半径退化成什么？此时「球」变成了什么图形？

结论

任意长方体的八个顶点总在同一个球面上：球心是体对角线 AC₁ 的中点，半径 R = √(a²+b²+c²)/2，即体对角线的一半；正方体 a=b=c 时 R = (√3/2)a，是长方体的特例。

注意事项

  • 本页为虚拟仿真，滑块范围 a、b、c ∈ [1, 10]，超出范围不讨论；数值均为无量纲单位长度。
  • 球面为半透明绘制，若遮挡棱线可点击「球面：隐藏」按钮后对照观察顶点位置。
  • 旋转视角与缩放仅改变观察方向，不改变几何关系；低性能设备上可减少拖动频率。
  • 记录表中「顶点距球心」一列应与 R 完全一致，若出现偏差请检查是否误读了直径。
