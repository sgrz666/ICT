探究浮力大小与排开液体体积、液体密度的关系

学习目标：
1. 能通过调节物体浸入液体的体积，观察并说出弹簧测力计示数随浸入体积增大而减小的现象；
2. 能根据弹簧测力计示数差计算浮力，并验证 F浮 = G排；
3. 能通过改变液体密度比较浮力大小，归纳浮力与排开液体体积、液体密度的关系。
物体重力 G = 2.000 N
弹簧测力计拉力 F = 1.020 N
浮力 F浮 = G − F = 0.980 N
排开液体重力 G排 = ρ液·g·V排 = 0.980 N
结论引导（自己填一填）：
① 液体密度不变时，V排越大，F浮越____（填大/小），两者成____比。
② 排开体积不变时，ρ液越大，F浮越____，两者成____比。
③ 比较 F浮 与 G排 的大小：F浮 ____ G排（填 > / < / =）。
