# 03_generator_agent/templates — 兜底代码模板目录

本目录存放生成角色的离线兜底 HTML 模板。

## 目录职责与内容

- **职责**：在外部大模型不可用（如无 API Key 或网络中断时）或使用 `--template-only` 调试参数时，作为保底输出，确保全流水线端到端可验证。
- **文件**：
  - `ohm_law_experiment.html`：包含标准 Canvas 电路仿真、电压/电阻滑动变阻器、数据记录表与欧姆定律即时验证的单文件电路实验模板（带 4 个插槽占位符）。

## 与上下层的关系

- **上游**：人工维护的标准物理实验示范页面。
- **下游**：`generator_agent.py` 当模型生成失败或进入保底模式时，加载此模板替换占位符后输出到 `output/`。

## 已知的坑与纪律

- 兜底模板目前仅内置电路欧姆定律实验，在非电路主题下不可强行伪充通用学科实验。
