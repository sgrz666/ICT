# 06_full_catalog/ — 全学科案例大纲生成与目录库

**职责**：汇集全学科（物、化、生、数、地、信）实验清单，支持自动化导出 JSON、CSV 和 Markdown 格式的大纲库。

## 内容

| 文件 | 说明 |
|---|---|
| `build_catalog.py` | 全学科大纲自动化构建与多格式同步导出脚本 |
| `全学科案例清单.json` | 全量实验条目元数据定义（含学科、年级、难度、关键公式） |
| `全学科案例清单.csv` | 教学专家与教研人员可直接表格审查的 CSV 版本 |
| `全学科案例清单.md` | 便于阅读和索引的 Markdown 文档版本 |

## 与上下层的关系

- **父层索引**：[`../README.md`](../README.md)。
- **构建入口**：运行 `python build_catalog.py` 刷新 CSV/JSON/MD 产物。

## 已知的坑与纪律

1. **同源同步**：改动清单必须运行 `build_catalog.py` 确保 CSV、JSON 与 MD 保持逐条一致。
