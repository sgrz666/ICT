# 12_showcase_plan/ — 演示成果规划与全景图

**职责**：制定用于比赛答辩与成果展示的演示案例编排规划、时间轴以及成果全景矢量图。

## 内容

| 文件 | 说明 |
|---|---|
| `build_plan.py` | 演示规划数据解析与多格式同步脚本 |
| `gen_svg.py` | 展示全景图 SVG 动态绘制脚本 |
| `展示规划清单.csv` | 演示例程、重点关注指标与讲解答辩要点表格 |
| `展示规划清单.md` | 演示全景实施说明与流程步骤 |
| `展示全景图.svg` | 生成的答辩成果全景矢量图 |

## 与上下层的关系

- **父层索引**：[`../README.md`](../README.md)。
- **构建入口**：运行 `python gen_svg.py` 刷新矢量图。

## 已知的坑与纪律

1. **时序可控**：演示例程必须控制在答辩限制时间（5-8分钟）内完成全闭环。
