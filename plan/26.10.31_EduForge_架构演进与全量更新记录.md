## 二、 六大核心更新模块深度拆解

### 1. `code/eduforge/services/agent-runtime` — 启智原生 dsh 运行时落盘
- **定位**：使用固定版本官方 TypeScript/Cordis 内核运行「启智 Web」，解决官方 2.7GB 大仓难以独立部署和分发的痛点。
- **核心文件与职责**：
  - [`agent-runtime.ps1`](../code/eduforge/services/agent-runtime/agent-runtime.ps1)：统一操作入口，支持 `doctor`、`web`、`sdk`、`verify`、`package`；
  - `src/runtime.mjs`：原生进程生命周期管理，支持指定隔离数据目录与工作区（默认 `%LOCALAPPDATA%\EduForge\agent-runtime`）；
  - `src/composition.mjs` & `config/`：预设隔离机制：
    - `physics-lab`（教学实验）：严格仅暴露 6 个 `experiment_*` 工具，禁止任意命令行与任意写；
    - `eduforge-dev`（开发助手）：受控提供文件管理、PowerShell、技能、Todo/Plan/Goal 与子智能体；
  - `src/package.mjs` & `src/package-graph.mjs`：Windows 便携发行打包器，剪枝无关文件，产出精简独立的 Windows 发行包（`D:\EduForge-release`）；
  - `src/verify.mjs`：端到端便携性与权限自动化验收脚本；
- **验收证据**：报告落盘于 [`../../output/eduforge/reports/native-dsh-portable-verification.json`](../output/eduforge/reports/native-dsh-portable-verification.json)，实测预设分离、权限阻断、Web HTTP 200 响应全部通过。

### 2. `deep-agent/dsh-core` — 纯 Python 轻量提纯 Agent 内核
- **定位**：彻底摆脱 Node.js monorepo 与重型 SWE-bench 依赖，以纯 Python（>=3.10）实现高内聚、零 C++ 编译的工业级智能体运行内核。
- **核心子系统与实测状态**（`pytest tests/` 51 项测试 100% 绿灯）：
  1. `file/`：安全文件管理、原子写、基于正则的精准行替换、驱动器绝对路径包含断言（杜绝 `..` 符号逃逸）；
  2. `sandbox/`：Windows 原生受控子进程执行、进程树递归清理、执行超时上限控制；
  3. `session/`：Format v4 格式事件溯源流式日志、表面投影模型、状态机与 JSONL 持久化；
  4. `memory/`：Token 消耗估算、工具大输出阶段剪裁、KV-Cache 友好的八段式上下文摘要压缩；
  5. `guard/`：防模型死循环守卫（第 3、5、8 次阶梯式提醒）与工具调用超时切断；
  6. `autonomy/`：`PlanModeManager`（只读探索门禁）、`TodoManager`（任务追踪）、`GoalManager`（跨轮自治驱动，强制 3 轮最小尝试）；
  7. `skill/`：`SKILL.md` 动态扫描发现、按需全文加载、系统提示词 `in_history` 追加更新（保住前缀缓存）；
  8. `subagent/`：支持 `spawn`（独立全新会话）与 `fork`（继承已完成轮次前缀，零拷贝复用缓存）子智能体派生；
  9. `interaction/`：结构化澄清提问、敏感操作人工审批流转与正式交付物签发；
  10. `labkit/`：原生 Python 桥接物理实验 6 工具，直通教学交付。

## 三、 当前已知边界与下阶段焦点

1. **双栈融合推进**：`services/agent-runtime`（Node 原生环境）与 `deep-agent/dsh-core`（纯 Python 环境）目前作为双轨并行运行。下一步重点是将 Python 业务逻辑通过官方 SDK 协议与 agent-runtime 进程平滑对接。
2. **Docker 沙箱隔离**：当前在 Windows 本地采用进程级受控沙箱与安全路径判定（`workspace-write` + `assert_path_contained`）；若部署至公网生产环境，仍需配套容器级虚拟化隔离。
3. **Ray Optics 单文件封装**：上游 Ray Optics 原生运行时包含 HTTP 异步取词逻辑，需进一步内联 i18n 字典，彻底消灭所有边界跨域警报。
