# 原生 dsh 精简实施记录

## 决策

采用官方 TypeScript/Cordis 内核，保留启智 Web；教学使用 physics-lab，开发使用 eduforge-dev。Python dsh-core 定位为研究原型，保留历史测试与缺口说明。上游固定到 `687f282e8625c6b8d11ff58211a90524be2e4317`，tracked 品牌补丁和未跟踪品牌源文件分别归档并记录哈希。

## 实施

- 新服务位于 [agent-runtime](../code/eduforge/services/agent-runtime/README.md)，组合、启动、校验、打包均在上游目录外实现。
- 本地配置以正式 bundle 注册。浏览器保存设置时重载仍保留组合；不使用仅内存追加层。
- 教学工具白名单在注册和执行层成立；真实 LabKit 使用可搬迁资源根、独立输出根和每次调用的 UUID 目录。
- HTML/证据/设计互绑，真实浏览器复算后交付；同名并发构建互不覆盖。
- 官方 SDK JSON-RPC 保留开发核心；Web 双预设尚未接入 EduForge Python Worker 和教师业务界面。
- Windows x64 发行候选含实体 npm 多版本依赖、Node、Headless Shell 和实验资源；逐文件 inventory 校验拒绝篡改与缺失。

## 实况与复核

源码与仓库外发行均已执行实际启动、教学实验构建、工具隔离、原生文件/进程越界拦截、运行中取消、审批拒绝、SDK 握手及浏览器预设/设置重载/拒绝按钮检查。真实模型缺少当前进程凭据，保留 pending，不使用 mock 作为通过依据。

完整结果与单次启动/内存/模块测量见 [生成的实施报告](../output/eduforge/reports/native-dsh-runtime-implementation.md) 及 [报告索引](../output/eduforge/reports/README.md)。测试规模仅引用 [test_totals](../code/eduforge/catalog/engines/ray-optics.yaml)，本文件不复制计数。

## 使用与回退

在仓库根运行 `code/eduforge/services/agent-runtime/agent-runtime.ps1 doctor`，再运行 `web -Port 3082`。模型配置页设置 API Key 后可使用；显式 `verify -Live` 执行真模型验收。默认数据位置为 `%LOCALAPPDATA%/EduForge/agent-runtime`，旧会话/凭据不自动迁移。停止新进程即可继续使用原上游启动方式。
