# 凹透镜发散与成像实验

## 教学目标
1. 观察平行光或点光源经过凹透镜后的发散光路特征。
2. 验证凹透镜成像规律：对于任意实物（物距 $u > 0$），凹透镜只能成正立、缩小的虚像，且像距绝对值小于焦距绝对值（$|v| < |f|$）。
3. 学习透镜成像公式的高斯形式在发散透镜中的符号规则（焦距 $f < 0$，虚像像距 $v < 0$）。

## 物理原理
理想薄凹透镜的高斯成像公式：
$$\frac{1}{u} + \frac{1}{v} = \frac{1}{f}$$
其中 $f < 0$ 为凹透镜负焦距，$u > 0$ 为物距。
像距计算：
$$v = \frac{f \cdot u}{u - f} = \frac{-|f| \cdot u}{u + |f|} < 0$$
横向放大率：
$$m = -\frac{v}{u} = \frac{|f|}{u + |f|} > 0$$
因 $u > 0$，必有 $0 < m < 1$，故恒为正立、缩小的虚像。
