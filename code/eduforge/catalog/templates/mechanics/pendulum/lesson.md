# 单摆周期与简谐振动 — 教学文案

本模板把「单摆周期」拆成两个配方：先看摆长如何决定周期，再看振幅增大时小角度近似何时失效。
页面默认使用配方参数，学生可以拖动摆长与初始角，实时看到摆角、周期读数与解析对照。

## 配方 1：摆长与周期（period-length）

- **实验目的**：验证 `T = 2π√(L/g)`；摆长翻 4 倍，周期变 2 倍。
- **操作步骤**：固定初始角 5°；把摆长依次设为 0.5 m、1.0 m、2.0 m；记录每次的周期。
- **观察要点**：周期随摆长增大而变长，但**不是线性**——L 变 4 倍，T 只变 2 倍。
- **常见误区**：认为「摆长越长，摆得越慢，所以周期与摆长成正比」。实际是平方根关系。

## 配方 2：振幅与周期（angle-correction）

- **实验目的**：验证小角度近似 `T≈2π√(L/g)` 的适用范围；理解 30° 时为什么需要椭圆积分修正。
- **操作步骤**：固定摆长 1.0 m；把初始角依次设为 5°、10°、30°；记录周期，并与小角度公式、精确解对照。
- **观察要点**：5° 与 10° 时小角度公式误差小于 0.2%；30° 时周期比小角度预测长约 1.7%，不能再用近似式。
- **常见误区**：把「单摆周期与振幅无关」当成无条件成立。它只在**小振幅**下近似成立。

## 页面上的「解析对照」是什么

实线是 matter-js 按固定步长（1/240 s）真实步进出来的摆角时程；虚线是解析式。
周期由角度过零检测得到，再与 `2π√(L/g)`（小角度）和 `4√(L/g)·K(sin(θ₀/2))`（精确解）对照。
若读数明显偏离，说明场景被改坏（例如约束长度被改动），页面会显示验收不通过的标记。
