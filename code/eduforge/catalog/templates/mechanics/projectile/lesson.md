# 抛体运动 — 教学文案

本模板把「抛体运动」拆成三个配方。每个配方只改一组参数，学生打开页面后可以拖动滑块，
实时看到轨迹、解析曲线与 T / R / H 读数。页面默认使用配方参数，可直接投给学生。

## 配方 1：平抛（horizontal）

- **实验目的**：验证水平抛出时，竖直方向是自由落体；飞行时间只由高度决定，射程与初速度成正比。
- **操作步骤**：保持发射角 0°、初始高度 20 m；把初速度从 10 m/s 调到 25 m/s；记录每次的射程与飞行时间。
- **观察要点**：飞行时间几乎不变，射程随初速度近似线性增大；最高点就是抛出点。
- **常见误区**：把「水平速度大」误认为「下落更慢」。竖直方向与水平方向相互独立。

## 配方 2：斜抛 45°（oblique45）

- **实验目的**：验证射程公式 `R = v₀²sin2θ/g`，理解 45° 时射程最大。
- **操作步骤**：固定初速度 20 m/s、初始高度 0；把发射角从 15° 调到 75°；记录射程、最高点、飞行时间。
- **观察要点**：射程在 45° 附近达到最大值；最高点与飞行时间随角度增大而增大。
- **常见误区**：认为「角度越大射得越远」。角度增大提高滞空时间，但水平分速度下降，二者乘积在 45° 最大。

## 配方 3：互补角（complementary）

- **实验目的**：验证 30° 与 60° 互为余角时射程相等（`sin2θ` 相同），射程随角度先增后减。
- **操作步骤**：固定初速度 20 m/s、初始高度 0；分别设置 30° 与 60°，记录射程并比较；再试 40° 与 50°。
- **观察要点**：两组射程在误差范围内相等；改变初速度时，这个结论仍然成立。
- **常见误区**：把「射程相等」误认为「轨迹相同」。两条轨迹的最高点与飞行时间明显不同。

## 页面上的「解析对照」是什么

实线是 Matter.js 按固定步长（1/240 s）真实步进出来的轨迹；虚线是运动学解析式。
两者在同一组参数下应当重合到 1% 以内。若明显分离，说明场景被改坏（例如阻力没有置 0），
页面会显示验收不通过的标记。
