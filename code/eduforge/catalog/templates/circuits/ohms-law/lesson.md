# 直流电路：欧姆定律与串并联 — 教学文案

本模板把直流电阻电路拆成三个配方。每个配方只改电源电压与电阻，页面上的电路图、电流表/电压表读数
会实时更新，并与解析式对照。

## 配方 1：欧姆定律（ohms-law）

- **实验目的**：验证 `I = U / R`；同一电压下，电阻越大电流越小。
- **操作步骤**：固定电压 5 V；把电阻依次设为 100 Ω、220 Ω、470 Ω；记录电流表读数。
- **观察要点**：电流与电阻成反比；电阻翻倍，电流减半。
- **常见误区**：把「电阻越大，电流越大」当作结论。电压不变时恰好相反。

## 配方 2：串联（series）

- **实验目的**：验证串联电路电流处处相同、电压按阻值分配，`R总 = R1 + R2`。
- **操作步骤**：固定电压 5 V、R1=100 Ω；把 R2 从 100 Ω 调到 300 Ω；记录总电流与两只电阻上的电压。
- **观察要点**：电流只有一条路径；阻值大的电阻分到的电压更大；`U1 + U2 = U电源`。
- **常见误区**：认为「电流经过第一个电阻后被消耗掉一部分」。串联电流处处相同。

## 配方 3：并联（parallel）

- **实验目的**：验证并联电路各支路电压相同、电流按电阻反比分配，`1/R总 = 1/R1 + 1/R2`。
- **操作步骤**：固定电压 5 V、R1=100 Ω；把 R2 从 100 Ω 调到 300 Ω；记录两支路电流与总电流。
- **观察要点**：两支路电压都等于电源电压；阻值小的支路电流大；总电流等于各支路之和。
- **常见误区**：把并联总电阻当成 `R1 + R2`。并联总电阻小于任一支路电阻。

## 页面上的「解析对照」是什么

实线电路由 MNA 节点法求解，读数与解析式 `I=U/R`、串并联公式对照。
MNA 对线性电阻电路是精确解，页面读数与解析值应在双精度下相同；若明显偏离，说明电路被改坏。
