# Ray Optics 实验定制规范

本技能向负责代码级实验定制的 Deep Agent 阐明 Ray Optics 引擎的架构约束、数据边界与代码接口。

## 1. 交付文件边界

每次定制任务仅允许交付以下两份 TypeScript 文件（其余修改不予采纳）：
1. `src/lesson.ts`：教学步骤、实验引导文本、问题与观察记录表定义；
2. `src/controls.ts`：与上游仿真交互的受控参数滑块、开关控件与响应回调。

## 2. 仿真数据与对象绑定纪律

- **对象身份绑定必须使用 `name` 字段**：上游编辑器中的 `objs` 数组顺序不稳定（拖动、删除、重排均会导致下标移位），绝对禁止使用数组索引（如 `objs[0]`）寻址对象。
- **白名单字段约束**：禁止向下游原生场景注入未登记的自定义 key（如 `eduforge_id`），否则上游加载器会置 `scene.error` 并拒绝渲染。
- **单位换算**：上游内部坐标为无量纲纯场景像素，教学单位与物理量换算必须严格遵循模板 `manifest.yaml` 声明的 `units_per_unit`（凸透镜模板为 10 像素 = 1 cm）。

## 3. 验证与发布

所有代码修改将注入全新沙箱，重新执行无头仿真测试和物理公式核验：
- 凸透镜焦距必须大于 0；
- 像距与物距必须遵循薄透镜高斯公式 \(1/u + 1/v = 1/f\)；
- 严禁篡改验证用例或门禁规则。
