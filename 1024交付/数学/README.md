# 数学/ — 数学学科交互实验交付包

**职责**：存放数学学科 4 个核心教学探究实验的独立离线发布包（ZIP 格式，包含交付 HTML、CSS 样式、Logo 资产及交互脚本）。

## 内容

| 交付包 | 覆盖知识点 | 交付形态 |
|---|---|---|
| `二次函数图像与参数关系.zip` | 抛物线顶点坐标、开口方向、对称轴、a/b/c 动态滑块交互与轨迹追踪 | 独立离线交互实验包 |
| `平面截正方体.zip` | 空间几何、任意平面截正方体截面多边形（三角形、四边形、五边形、六边形）三维可视化 | 独立离线交互实验包 |
| `椭圆离心率.zip` | 圆锥曲线第一定义、焦半径、离心率 e 变化对椭圆扁平程度的实时驱动 | 独立离线交互实验包 |
| `长方体外接球.zip` | 立体几何外接球球心确定、体对角线与球直径公式对账 | 独立离线交互实验包 |
