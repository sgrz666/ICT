# 物理/ — 物理学科交互实验交付包

**职责**：存放物理学科 4 个核心教学实验的独立离线发布包（ZIP 格式，包含交付 HTML、CSS 样式、Logo 资产及交互脚本）。

## 内容

| 交付包 | 覆盖知识点 | 交付形态 |
|---|---|---|
| `伏安法测电阻.zip` | 闭合电路欧姆定律、滑动变阻器限流/分压分流、电表内接与外接读数误差 | 独立离线交互实验包 |
| `探究浮力规律.zip` | 阿基米德原理、浸入体积与排开液体重力、密度与浮沉条件 | 独立离线交互实验包 |
| `杠杆实验.zip` | 杠杆平衡条件（动力×动力臂=阻力×阻力臂）、力矩平衡、支点动态调节 | 独立离线交互实验包 |
| `验证动量守恒.zip` | 完全弹性碰撞与非弹性碰撞、动量守恒定理、动能损耗曲线 | 独立离线交互实验包 |
