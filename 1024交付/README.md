## 与上下层的关系

- **上游流水线**：由教学实验生成流水线（`2026-10-18-11-03-28/`）与 LabKit 验证套件（`code/eduforge/tools/labkit/`）程序化生成并经无头浏览器审查通过。
- **下游消费方**：直接作为竞赛作品答辩、评审离线演示和教师端分发成果包。

## 已知的坑与纪律

1. **单文件与资源离线**：每个实验 zip 包解压后均为完整自治的 HTML+CSS+JS 结构，必须保证在断网环境（`file://` 协议）下完全可交互。
2. **中间件缓存**：`_gif_frames*` 与 `_gif_work` 属于大体积切帧图片缓存，不纳入主版本库跟踪。
